## Summary

전체 시스템 MVP 완성 — 게임 엔진 + RL 파이프라인 + 웹 대시보드 + 3-환경 Docker Compose + CI/CD 의 첫 feature-complete 릴리스. 9개 엔지니어링 롤이 각자 영역에서 초기 구현 완료.

## Features

### Game Engine (AI Engineer)
- 물리 기반 2D 피카추 배구 엔진 (`backend/game/engine.py`) — 충돌 감지, 중력, 점프, 다이브, 파워 히트, 15-점 선승 득점
- 게임 상수 (`backend/game/constants.py`)
- Rule-based Bot L1~L5 (`backend/game/bot.py`) — `reaction_delay`, `prediction_error`, `miss_probability` 차등
- Gymnasium 호환 RL 환경 (`backend/rl/env.py`) — Observation 12D, Action Discrete(6), reward shaping

### Training Pipeline (Trainer)
- PPO 훈련 매니저 (`backend/rl/trainer.py`) — 백그라운드 스레드 기반, curriculum learning, 8 parallel SubprocVecEnv
- 기본 하이퍼파라미터: lr=3e-4, n_steps=2048, batch=64, epochs=10
- 콜백: MetricsCallback, CheckpointCallback, LiveFrameCallback

### Evaluation (Evaluator)
- `evaluate()`: N 게임 실행 후 win_rate / avg_score / avg_rally_length
- `compare_checkpoints()`: 다수 체크포인트 비교

### Backend (Backend Engineer)
- FastAPI REST API (`backend/app/api/routes.py`) — health, training, games, replays, models, evaluation
- WebSocket 실시간 통신 (`backend/app/ws/`) — training 제어 + 실시간 metrics/frame/result 스트리밍
- MongoDB (motor async) — games / metrics / evaluations 컬렉션
- 서비스 계층 — TrainingService, EvalService, GameService, ReplayService
- Replay msgpack 직렬화 (최근 1000개 유지)

### Frontend (Frontend Engineer)
- React 19 + TypeScript + Vite 8 초기 구성
- Dashboard (`/`) — TrainingControls, HyperparamForm, MetricsChart (Recharts), GameCanvas (PixiJS 30→60fps 보간)
- Replay (`/replay/:id`) — ReplayPlayer, ReplayList
- Evaluation (`/evaluation`) — EvalPanel, EvalChart
- Hooks: useWebSocket (자동 재연결), useTrainingState
- API 클라이언트 (`frontend/src/lib/api.ts`)

### Design System (Designer)
- Arcade-themed dark mode
- CSS custom properties 기반 디자인 토큰 (`frontend/src/styles/tokens.css`)
- 글로벌 스타일 + 컴포넌트별 CSS

### DevOps
- Backend Dockerfile (Python 3.11 multi-stage), Frontend Dockerfile (Node build → Nginx), `.dockerignore`
- Docker Compose 3종: prod / dev / qa
- GitHub Actions CI — Python lint + test, Frontend lint + build
- 운영 스크립트: deploy-{dev,qa,prod}.sh, promote.sh, release.sh, setup.sh, cleanup-replays.sh, status.sh
- 환경별 .env 템플릿

### QA
- Backend 10 테스트 모듈 — engine, bot, env, trainer, evaluator, API, WS, integration, scenarios, coverage gaps
- Frontend 4 테스트 — TrainingControls, GameOverlay, ReplayControls, useWebSocket

## Architecture (v0.1.0 시점)

단일 Docker Compose 안에 backend + frontend + mongodb 가 함께 돌아가는 모놀리식 배포. Two-server split 은 v0.2.1 에서 도입 (`75fb4292`).
