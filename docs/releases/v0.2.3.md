## Hotfixes Included

### 1. BE-6 WS broadcast restore — `91c7233d`
**Problem**: v0.2.2 의 `fb1f5e64 perf(ws): parallel broadcast with serialize-once fan-out (BE-6)` 이후 `training:status` 메시지가 일부 구독자에게 도달하지 못함. PM 이 brotherly observed: Start 버튼이 계속 활성화, status badge 가 "stopped" 로 유지, 그러나 백엔드 training thread 는 실제로 돌고 있음. QA 재검증에서 100% 재현.

**Fix**: `asyncio.gather(..., return_exceptions=True)` 기반 fan-out 경로에서 개별 구독자 전송 실패가 전체 broadcast 를 조기 종료하지 않도록 보정. `backend/tests/test_training_status_broadcast.py` 268 라인 회귀 스위트 신설하여 `training:status(running|stopped|paused|resumed)` 브로드캐스트 보장.

### 2. Net-collision vx reversal guards — `bf6397cc`
**Problem**: v0.2.2 의 `b0d0aaee fix: port game engine faithfully to gorisanson/pikachu-volleyball original` 포팅 후 공이 네트 x 중심(~216)에 도달해도 vx 가 뒤집히지 않아 네트를 통과하거나 붙어버리는 현상. `test_engine.py::TestBallNetCollision::test_ball_vx_reverses_on_net_collision` 실패.

**Fix**: net-collision 분기 가드 강화 + 테스트 케이스 추가로 원본 거동 고정 (`ball at x≈216, vx>0 → vx reverses to ≤0`).

### 3. Bot stochastic variance — `6af36c0c`
**Problem**: Faithful physics port 이후 bot 플레이가 지나치게 반복적. 같은 외부 엔트로피면 프레임 단위로 같은 경기가 반복됨 — RL 훈련이 특정 패턴에 과적합될 위험.

**Fix**: `BotParams` 에 stochastic knobs 4종 추가:
- `jump_jitter` — per-frame uniform jitter on jump threshold
- `angle_variance` — non-default power-hit angle probability
- `hesitation_rate` — movement hesitation probability
- `trajectory_noise_scale` — frames-to-intercept scaled noise

L1~L5 모두 nonzero variance 확보. L5 는 여전히 distinct skill edge 유지 (prediction_error 0.0 → 0.03 정도로 최소 노이즈만).
