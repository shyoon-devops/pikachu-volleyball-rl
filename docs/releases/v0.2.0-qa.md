## Changes Included

### Features
- Game engine — physics, collisions, scoring, 15-point match (`backend/game/`)
- Rule-based bot L1~L5 difficulty levels (`backend/game/bot.py`)
- Gymnasium RL environment — obs 12D, action Discrete(6) (`backend/rl/env.py`)
- PPO training pipeline — curriculum learning, 8 parallel envs (`backend/rl/trainer.py`)
- Callbacks — MetricsCallback, CheckpointCallback, LiveFrameCallback (`backend/rl/callbacks.py`)
- Model evaluation — win_rate, avg_score, checkpoint comparison (`backend/rl/evaluator.py`)
- FastAPI REST API + WebSocket real-time (`backend/app/`)
- React 19 dashboard — PixiJS game canvas, Recharts metrics, replay player (`frontend/`)
- Arcade-themed dark mode design system (`frontend/src/styles/`)
- 3-environment Docker Compose — dev/qa/prod
- GitHub Actions CI/CD — lint, test, coverage, CD workflows
- Original pikachu volleyball sprite sheet and sound assets

### Bug Fixes
- `dbdb826` fix: handle invalid ObjectId and missing model file gracefully
- `5c30671` fix: guard against duplicate training:start causing WebSocket crash
- `52dfd43` fix: add replay list API, complete frame serialization, backfill legacy replays
- `41f4fdb` fix: resolve conflict markers in dev branch frontend files
- `46e9aa5` feat: improve reward shaping for faster PPO convergence

### Refactors
- CSS separated from TSX — designer owns .css files only
- All inline styles converted to className + CSS files
- CSS selectors aligned with FE className conventions
- Responsive breakpoints and element-level selectors enhanced
- CI/CD pipeline enhanced with coverage reports, CD workflows, self-hosted runner
