## Summary

v0.2.4 배포를 3 환경에 완료한 직후, Phase 2 로 계획된 gameplay feel 재정비 + 메트릭 차트 충실도 + 봇 난이도 상향 작업이 2 단계 배포 창(FE 22:03, BE 22:05)에 걸쳐 runtime `6f4a057f` 로 묶였다. 직후 사용자 실사용에서 확인된 **15점 도달 시 match-end freeze tick 누락 (P0)** 버그를 `e9f72459` 로 수정하고 `cd1e6a39` 머지로 반영. v0.2.5 태그는 match-end freeze 까지 포함한 dev HEAD 를 최종 컷 지점으로 잡음.

Phase 2 에서 해결된 주요 사용자 리포트 이슈:

1. 15점 도달 후 마지막 포인트 장면이 무한 고착 → 다음 매치 불가 (P0 핫픽스)
2. 새로고침 시 차트가 비워짐 — `/timeseries` hydration 으로 seed 복원
3. Recent Games 배지가 "L" 로만 표시 (bot_level 없음) — fallback + 레거시 백필 마이그레이션
4. L5 봇 상대로 인간이 역전 가능 — aggression / net-bias 2 축 튜닝
5. 스카이 그라디언트에 RGB 줄무늬 — PixiJS `NEAREST` 필터 + `antialias:false`
6. 강타/다이브/freeze-frame 시각 피드백 부재 — Designer D11-D15 + `punch_effect_radius`, `is_diving` 서버 권위 전송
7. `log_interval` 과도 샘플링 + `/timeseries` 상한 1000 포인트 한계 → 해상도/장기 runs 개선

## Hotfixes & Improvements Included

### 1. P0 match-end freeze tick — `e9f72459` (merge `cd1e6a39`)
**Problem**: 15점 매치 위닝 포인트 직후 `_tick_post_score_freeze` 가 호출되지 않아 freeze 타이머가 멈추지 않음 → 마지막 포인트 장면이 무한 고착 → 다음 매치 진행 불가. 사용자가 직접 새로고침하거나 Stop/Start 로 우회해야 함.

**Fix**: 득점 처리 경로에서 match-winning point 에도 freeze tick 이 확실히 불리도록 게이트 교정. 회귀 케이스 `test_engine.py::TestMatchEndFreeze` (신규) 추가.

### 2. Score hold grounded-ball frame — `6ff911d9`
**Problem**: 득점 후 공이 지면에 닿은 프레임이 서버에서 즉시 다음 서브 상태로 전환되어 FE 가 마지막 포인트의 시각적 결말을 받지 못함.

**Fix**: 득점 발생 프레임을 짧게 홀드한 뒤 다음 서브로 넘어가도록 엔진 tick 을 조정. 원본 가독성 회복.

### 3. `last_frame` seed on training start — `ca4cb608`
**Problem**: 훈련 시작 직후 첫 WS `training:frame` 이 도착하기 전에 FE 새로고침이 일어나면 `/api/training/current_frame` 이 `None` → 404 로 캔버스 빈 상태.

**Fix**: `TrainingManager` 가 훈련 시작 시점에 즉시 첫 frame 을 `last_frame` 에 시드 → REST 경로는 언제나 200 보장.

### 4. Chart hydration from `/timeseries` on mount — `917c53cc`
**Problem**: 새로고침 직후 차트가 빈 상태. WS `training:metrics` 는 새 포인트부터 오므로 이전 포인트가 복원되지 않음.

**Fix**: mount effect 에서 `GET /api/training/metrics/timeseries` 로 trailing window seed → 이후 WS incremental 이 자연스럽게 이어짐.

### 5. `log_interval` 100 → 256 + `/timeseries` cap 1000 → 10000 — `856f689e`
**Problem**: `log_interval=100` 이 장기 실행 시 MongoDB insert I/O 병목을 유발. `/timeseries` 기본 cap 1000 도 trailing window 가 짧아 새로고침 시 차트 앞부분 누락.

**Fix**: 두 쪽을 함께 완화. `log_interval` 256 으로 상향 + `/timeseries` cap 10000. 포인트 누락 없이 성능/해상도 개선.

### 6. Sampling cadence label "N pts · M steps" — `2ed23c94`
**Problem**: 사용자가 차트가 전체 훈련의 몇 % 를 보여주는지 알 수 없음.

**Fix**: 차트 헤더에 `N pts · M steps` 라벨 추가. 전체 trailing window 맥락 가시화.

### 7. WS dead-letter routing for missing `bot_level`/`experiment_id` — `05ffd073`
**Problem**: 과거 코드는 필드 누락 시 silent L1 fallback → 해당 데이터가 L1 통계에 섞여 들어감.

**Fix**: 누락 시 dead-letter 로 분기 + 로그. L1 데이터 오염 차단 + 품질 투명화.

### 8. Recent Games bot level fallback + legacy backfill — `b9819d5a` + `2e6bf373` + `116dd6ae`
**Problem**: 레거시 문서에 `bot_level` 이 없어 Recent Games 배지가 빈 "L" 로만 렌더.

**Fix**:
- FE: 누락 시 fallback (예: `—` 또는 이전 레벨 상속) 으로 대체 — 빈 라벨 제거
- BE: `backend/scripts/migrate-games-bot-level.py` 로 과거 문서 backfill + `--mode=purge-pre-fix` 로 회복 불가 문서 삭제 Option B 제공

### 9. Sky RGB stripe regression — `ff24cc9a` + `f6e73e86`
**Problem**: 일부 브라우저/GPU 조합에서 PixiJS 가 스카이 그라디언트를 RGB 줄무늬로 렌더. 특히 새로고침 직후 뚜렷.

**Fix**: PixiJS `Texture.filter = NEAREST` + `antialias: false` + `roundPixels: true` 조합으로 서브픽셀 샘플링 제거. 픽셀 아트 원본 스타일과 정합.

### 10. Build: exclude `*.test.{ts,tsx}` from `tsconfig.app.json` — `630b66c5`
**Problem**: 프로덕션 번들에 Vitest 타입 시그니처가 끌려오던 문제. 번들 크기 + 타입 누출.

**Fix**: `tsconfig.app.json` 의 `exclude` 에 `*.test.{ts,tsx}` 추가.

### 11. Visual FX + Designer D11-D15 — `a8cd7c59` + `34137663` + `bad997f1` + `5f0b0cd7` + `743dc8ae` + `982e3a80`
- **D11 Dive sprite + motion-blur afterimage** (`a8cd7c59`): `is_diving` 상태 다이브 스프라이트 + 잔상
- **D12 Punch ring + D13 power-hit trail overlay** (`34137663`): 지면/강타 링, authoritative trail
- **D14 Recent Games bot level badges** (`bad997f1`): L1-L5 배지 색
- **D15 Score freeze-frame scoreboard flash** (`5f0b0cd7`): 득점 시 점수판 플래시
- **`ball.punchEffect{X,Y,Radius}` types** (`743dc8ae`): bottom-hit ring payload 타입
- **`punch_effect_radius` WS emit** (`982e3a80`): 서버 권위 링 반경

### 12. Bot difficulty L1-L5 upgrade + aggression/net-bias — `d2436993`
**Problem**: 사용자 리포트: "L5 상대로 인간이 역전 가능". L5 가 결정성+예측 정확도 위주로 튜닝되어 네트 압박/반응 속도가 낮아 관찰 가능한 허점.

**Fix**: 기존 prediction_error/angle_variance 축에 **aggression** + **net_bias** 2 축 추가. L1 은 기존 완화 수준 유지, L5 는 <10% 인간 승률 목표로 재튜닝. 단위 테스트 `test_bot.py` 확장.

### 13. Deploy / ops infra
- **`scripts/deploy-frontend.sh` auto-advances `github/<env>` ref** (`6f96d7fd`): 배포 step [6/6] 에서 runtime SHA 를 `github/<env>` 에 push → branch head 가 runtime 과 자동 정합
- **docker json-file log rotation + Round-2 disk cleanup** (`63bc1ca1`): dev/qa log 크기 폭증 방지
- **Incident postmortem publish** (`018a2be1`): `docs/incidents/20260412-dev-backend-stale.md`
