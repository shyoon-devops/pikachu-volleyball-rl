## Deployment Plan

### DevOps 배포 지시 (v0.2.2 GO signal)

```bash
# 1. dev 태그가 qa 로 promote
scripts/promote.sh dev-to-qa
git tag -a v0.2.2-qa $(git rev-parse github/qa) -m "v0.2.2 deployed to qa"
git push github v0.2.2-qa

scripts/deploy-qa.sh
scripts/deploy-frontend.sh qa

# 2. QA 검증 (qa reverify script 실행) 통과 후 prod
scripts/promote.sh qa-to-prod
git tag -a v0.2.2-prod $(git rev-parse github/prod) -m "v0.2.2 deployed to prod"
git push github v0.2.2-prod

scripts/deploy-prod.sh
scripts/deploy-frontend.sh prod

# 3. prod → main 머지
git checkout main && git pull github main
git merge github/prod --no-ff -m "merge: prod v0.2.2"
git push github main
git tag -f v0.2.2 $(git rev-parse main)  # main HEAD 에도 reachable 하게
```
