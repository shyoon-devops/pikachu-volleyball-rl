| 항목 | 내용 |
|------|------|

| 의존성 | 없음 |
| 리스크 | 낮음 |

**PM 의견**: 승인. 공수가 작고 UX 향상 효과가 즉각적. ReplayControls에 onKeyDown 이벤트만 추가하면 되므로 다른 작업에 영향 없음. Space(재생/일시정지), 좌우 화살표(프레임 이동), +/-(배속) 정도면 충분. QA 배포 전에 넣을 수 있으면 v0.2.0에 포함, 아니면 v0.2.1 패치.

### 2. MetricsChart 스무딩/줌 — ✅ 승인 (현재 스프린트)

| 항목 | 내용 |
|------|------|
| 우선순위 | P1 → **P1 유지** |
| 공수 | 1일 |
| 의존성 | 없음 |
| 리스크 | 낮음 |

**PM 의견**: 승인. 훈련 모니터링의 핵심 기능. PPO 훈련 시 메트릭이 노이즈가 많아서 스무딩 없이는 트렌드 파악이 어려움. Recharts의 brush 컴포넌트로 줌을 구현하고, 이동 평균(window=50)으로 스무딩하면 1일 내 가능. 다만 QA 통과 후 v0.2.1에 넣는 것을 권장 — QA 범위를 넓히지 않기 위해.

### 3. GameCanvas 반응형 스케일링 — ✅ 승인 (현재 스프린트)

| 항목 | 내용 |
|------|------|
| 우선순위 | P2 → **P1 상향** |
| 공수 | 0.5일 |
| 의존성 | 없음 |
| 리스크 | 낮음 |

**PM 의견**: P1으로 상향 승인. 현재 GameCanvas가 432x304 고정 사이즈라 작은 화면에서 잘림. ResizeObserver로 컨테이너 크기 감지 → PixiJS renderer.resize() 호출 + 비율 유지 스케일링이면 0.5일 충분. QA 환경에서도 다양한 해상도 테스트가 필요하므로 v0.2.0에 포함 권장.
