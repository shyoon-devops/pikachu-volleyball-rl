## 3. 스카이 RGB 스트라이프 근본 원인 + 수정 (report)

**디자이너 제보:** 캔버스 하늘 영역에 수직 RGB 줄무늬 발생.

**원인 조사 결과:**

- 스프라이트 아틀라스 바이너리는 **원본과 동일** (`sprite_sheet.png` md5 `4fc3712243966195534ee80e1ca81364` = `/tmp/pikachu-original/.../sprite_sheet.png`). 아틀라스 패딩도 `(0,0,0,0)` 투명으로 정상.
- 문제는 **PixiJS v8 렌더러 설정**:
  - Default scaleMode = `LINEAR`
  - `Application.init({ antialias: true, resolution: DPR, autoDensity: true })`
  - 위 조합에서 DPR>1일 때 sky_blue 16×16 타일 가장자리 텍셀이 sub-pixel 샘플링되면서 옆 투명 거터 픽셀로 번짐(bleed).
  - 12행 × 27열로 타일링되어 매 16px마다 수직 이음매가 RGB 스트라이프로 보임.

**수정 (커밋 `ff24cc9a`):**

```ts
// GameCanvas.tsx
TextureSource.defaultOptions.scaleMode = 'nearest'  // Assets.load 전에 설정
await app.init({
  ...
  antialias: false,    // 기존 true → false
  roundPixels: true,   // 스프라이트를 정수 픽셀로 스냅
})
```

**회귀 테스트:** `frontend/src/components/game/GameCanvas.pixel-art.test.ts` — 위 세 설정 라인을 소스 레벨에서 고정(pin). jsdom에서는 실제 PixiJS 렌더링이 안 되므로 설정 라인 자체를 테스트로 잠가 놓았습니다.

**검증:**
- `npx tsc --noEmit` → 0 error
- `npm run build` → 성공
- `npx vitest run` → 13 파일 / 99 테스트 전부 통과
