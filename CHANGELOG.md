# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-04-11

### Added
- Game engine with physics, collisions, scoring
- Rule-based bot with 5 difficulty levels
- Gymnasium-compatible RL environment
- PPO training pipeline with SB3 and callbacks
- Model evaluation system with version comparison
- FastAPI backend with REST API and WebSocket
- React + PixiJS frontend with dashboard, replay, evaluation UI
- Docker multi-environment setup (dev/qa/prod)
- GitHub Actions CI pipeline
